# ISC-S1

## 1. Software
Conjunto de programas, aplicaciones y datos que permiten que una computadora o dispositivo funcione y realice distintas tareas.

## 2. Procesos
Conjunto de pasos u operaciones ordenadas que se realizan para lograr un objetivo o resultado específico.

## 3. Sistema de cómputo
Conjunto de hardware, software y usuarios que trabajan de forma integrada para procesar información y obtener resultados.

## 4. Hardware
Conjunto de componentes físicos de una computadora, como el teclado, la pantalla, el mouse y la unidad central.

## 5. Dato
Representación básica de un hecho, valor o información que por sí sola no tiene significado hasta ser procesada.

## 6. Entrada
Información o datos que se introducen en un sistema de cómputo para ser procesados.

## 7. Salida
Resultado de la información procesada por un sistema de cómputo, que se presenta al usuario.

## 8. Almacenamiento
Proceso y capacidad de guardar datos e información para su uso posterior en un sistema de cómputo.

## 9. Sistema operativo
Software principal que administra el hardware de la computadora y permite la ejecución de aplicaciones.

## 10. Base de datos 
Conjunto organizado de datos relacionados entre sí, almacenados de forma estructurada para facilitar su acceso y gestión.

## 11. Computación en la nube
Uso de servicios informáticos a través de internet para almacenar, procesar y acceder a datos sin necesidad de equipos locales.

## 12. Inteligencia artificial (IA) 
Rama de la informática que desarrolla sistemas capaces de imitar funciones humanas como el aprendizaje, el razonamiento y la toma de decisiones.

## 13. Ciberseguridad
Conjunto de medidas y prácticas destinadas a proteger sistemas, redes y datos contra accesos no autorizados y ataques digitales.

## 14. Usuario
Persona que interactúa con un sistema de cómputo y utiliza sus programas y recursos para realizar tareas.

## 15. Archivo
Conjunto de datos almacenados en un dispositivo, identificado por un nombre y una extensión.
